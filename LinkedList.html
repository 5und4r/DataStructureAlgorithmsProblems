Three chains, three sets of rules. Insert, delete, search and reverse, then read the pointers doing the work in C++.

Singly Linked List

Every node holds a value and one pointer to the next node. The list is only walkable forward — to reach node i you must pass through every node before it. The last node's pointer is nullptr.

At a glance

  • Direction forward only
  • Extra pointer / node 0
  • Access by index O(n)
  • Insert at head O(1)

Doubly Linked List

Each node keeps a pointer to the next node and the previous one. The extra pointer costs memory but buys O(1) removal once you're holding a node, and traversal in either direction from a maintained tail.

At a glance

  • Direction both ways
  • Extra pointer / node +1 (prev)
  • Insert at tail O(1)
  • Delete at tail O(1)

Circular Linked List

The last node doesn't point to nullptr — it points back to the head, so the chain closes into a loop. Usually only a tail pointer is kept, since tail->next already gives you the head in O(1).

At a glance

  • Direction forward, loops
  • Terminator none — cycles
  • Insert at tail O(1)
  • Traverse must track a stop condition
