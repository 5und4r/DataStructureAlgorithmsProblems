    The theory, in six small ideas

    Every heap fact follows from two rules: a shape rule and an order rule. Learn these and the rest is just bookkeeping.

    1What is a binary heap?

    • A binary tree: every node has at most two children (left and right).
    • It is complete: all levels are full except maybe the last, which fills from left to right.
    • It follows the heap-order property: each parent is "better" than its children.
    • Its superpower: the best item is always at the root, so reading it takes O(1).
    • Think of a sports tournament bracket: the champion always sits at the top.

    2Shape rule: complete binary tree

    • Fill the tree level by level, left to right, like reading a book.
    • No gaps are allowed in the middle of a level.
    • Because of this, the height is always ⌊log₂ n⌋, so a heap of 1,000,000 items is only about 20 levels tall.
    • The shape rule is what lets us store the tree in a plain array with no pointers.

    3Order rule: Min-Heap and Max-Heap

    • Min-Heap: every parent ≤ its children, so the smallest value is at the root.
    • Max-Heap: every parent ≥ its children, so the largest value is at the root.
    • Siblings have no order between them. Left child may be bigger or smaller than right child.
    • A heap is not a sorted array, and it is not a binary search tree.

    4Stored as an array

    • Write the nodes level by level into an array, starting at index 0.
    • Moving around the tree becomes simple arithmetic, no pointers needed.
    • Example: node at index 1 (value 20) has children at 3 and 4, and its parent is at 0.
    • Leaves live at indices n/2 … n−1; every node before that has at least one child.
    parent(i) = (i − 1) / 2left(i) = 2·i + 1right(i) = 2·i + 2

    5The two repair moves

    • Heapify-up (bubble up) is used after insert. The new value starts at the bottom and swaps with its parent while it is better than the parent.
    • Heapify-down (sink down) is used after extract. The last value is moved to the root and swaps with its better child until both children are worse.
    • Each move walks one path of the tree, so each costs at most O(log n) swaps.
    • Build heap runs heapify-down from the last parent back to the root, which costs only O(n) in total.

    6How fast is each operation?

    Peek top (min / max)O(1)
    InsertO(log n)
    Extract topO(log n)
    Build heap from n itemsO(n)
    Search any valueO(n)
    Heap sortO(n log n)
    • Space needed: O(n) for the array. Heap sort itself sorts in place with O(1) extra space.
    • Heap sort is not stable: equal values may change their relative order.

    Worked example: insert 5 into a Min-Heap

    Starting heap: [10, 20, 15, 50, 40, 30]. Watch the new value climb.

    Step 1

    Add at the end

    5 goes to index 6, the first free slot. Its parent is index (6−1)/2 = 2, value 15.

    Step 2

    5 < 15, swap

    5 moves to index 2. Its new parent is index 0, value 10.

    Step 3

    5 < 10, swap, done

    5 reaches the root. Final array: [5, 20, 10, 50, 40, 30, 15]. Only 2 swaps.

    Where heaps are used

    Whenever you repeatedly need "the most urgent", "the cheapest" or "the biggest" item, a heap is usually the answer.

    🚑
    Max-Heap

    Priority queue

    Hospital emergency rooms treat the most critical patient first, not whoever came first.

    Critical (9) is served before fever (3), even if fever arrived earlier.
    🗺️
    Min-Heap

    Shortest paths (Dijkstra)

    Maps and GPS repeatedly pick the closest unvisited place. A Min-Heap hands it over in O(log n).

    Google Maps, network routing, game path-finding.
    📊
    Max-Heap

    Heap sort

    Build a Max-Heap, then keep moving the root to the end. Guaranteed O(n log n), in place.

    [12, 3, 17, 8] → [3, 8, 12, 17]
    🏆
    Min-Heap of size K

    Top-K items

    Keep only the K best scores. If a new score beats the smallest of the K, replace it.

    Top 3 of 1 million scores using only 3 slots of memory.
    ⚖️
    Max + Min Heap

    Running median

    A Max-Heap holds the lower half and a Min-Heap the upper half. The median sits at their tops.

    Live median of stock prices or sensor readings.
    🖥️
    Min-Heap

    CPU and job scheduling

    Operating systems and timers pick the task with the earliest deadline or highest priority next.

    Run the job due in 2 ms before the one due in 50 ms.
    🗜️
    Min-Heap

    Huffman coding

    Repeatedly merge the two least frequent symbols to build an optimal compression code.

    Used inside ZIP, JPEG and MP3 compression.
    🔗
    Min-Heap

    Merge K sorted lists

    Put the first item of each list in a heap, then always take the smallest and refill from its list.

    Merging log files from many servers by timestamp.

    1. better(a, b)
    One small function decides the heap type: a < b makes a Min-Heap, a > b makes a Max-Heap.
    
      
    2. push → heapifyUp
    Add the value at the end of the vector, then swap it with its parent while it is better.
    
      
    3. pop → heapifyDown
    Copy the last value to the root, remove the last slot, then sink the root down past its better child.
    
      
    4. build → O(n)
    Copy the array and call heapifyDown from index n/2 − 1 down to 0. Leaves need no work.
